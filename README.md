Desenvolvimento de um Sistema para Acompanhar as Atividades e Disciplinas dos Alunos do Instituto Bemmaker
________________________________________
🎯 Objetivo Geral
Desenvolver um sistema informatizado para acompanhamento acadêmico dos alunos do Instituto Bemmaker, permitindo o registro, monitoramento e análise das atividades e disciplinas cursadas, promovendo melhor gestão pedagógica e apoio à permanência estudantil.
________________________________________
🎯 Objetivos Específicos
1.	Criar banco de dados para cadastro de:
  
	●	Alunos
  
	●	Disciplinas
  
	●	Professores/orientadores
  
	●	Atividades acadêmicas
2.	Registrar frequência, notas e desempenho por disciplina.
3.	Implementar acompanhamento de entrega de atividades.
4.	Desenvolver painel de monitoramento para:
  
	●	Desempenho individual
  
	●	Desempenho por turma
  
	●	Evolução ao longo do tempo
5.	Gerar relatórios acadêmicos automatizados.
6.	Implementar sistema de alertas para:
	
	●	Baixa frequência
	
	●	Baixo desempenho
	
	●	Pendências acadêmicas
7.	Criar diferentes níveis de acesso (aluno, professor, coordenação).
8.	Garantir segurança e proteção dos dados dos estudantes.
________________________________________
📌 Justificativa

O acompanhamento manual do desempenho dos alunos pode gerar:

	●	Falta de visão integrada do progresso acadêmico
	
	●	Dificuldade na identificação precoce de evasão
	
	●	Retrabalho administrativo
	
	●	Falta de indicadores consolidados

Um sistema estruturado permite gestão pedagógica baseada em dados, promovendo:

	●	Monitoramento contínuo
	
	●	Intervenções preventivas
	
	●	Transparência no acompanhamento
	
	●	Melhor organização das informações acadêmicas
